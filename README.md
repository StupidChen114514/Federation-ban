# Federation-ban (fban) 🎮

**一个游戏社区反作弊协作平台，通过汇总多个平台的作弊者信息，共同维护公平的游戏环境。**

## 📝 项目简介

Federation-ban 是一个开源的游戏社区反作弊项目。我们收集并维护来自多个游戏平台的已知作弊者数据库，帮助游戏社区识别和封禁不诚实的玩家，共同营造良好的竞技环境。

### 核心使命
- 🛡️ **保护极客生态** - 维护良好的极客环境
- 🤝 **社区协作** - 集众多平台力量，共同对抗作弊
- 📊 **信息汇总** - 建立统一的作弊者黑名单数据库
- ✅ **证据驱动** - 所有记录都有截图证据支持

## 📋 贡献指南

### 如何添加新的作弊者信息？

我们接受两种方式提交作弊者信息：

#### 方式一：提交 Issue
1. 点击 **Issues** 标签页
2. 点击 **New Issue**
3. 使用以下格式填写信息：

```
标题: [作弊者] 用户ID | 封禁理由

内容:
- 用户ID: [平台ID]
- 平台: [coolapk/telegram/Other]
- 封禁理由: [简要描述体现的作弊语言或行为]
- 证据链接: [附加截图或视频链接]
```

4. **必须附带截图证据**（可在描述中粘贴图片或附件）

#### 方式二：提交 Pull Request
1. Fork 本仓库
2. 在相应平台的文件中添加记录，格式如下：

```
| 用户ID | 平台 | 封禁理由 | 提交日期 | 证据 |
|--------|------|---------|---------|------|
| [ID] | [平台] | [理由] | YYYY-MM-DD | [截图/链接] |
```

3. 提交 PR，**必须在 PR 描述中附带截图证据**
4. 等待审核和合并

### 提交要求

✅ **必须满足以下条件才能被接受：**

- [ ] 提供明确的用户ID（游戏平台ID、用户名等）
- [ ] 清晰地描述ta有作弊行为的理由（如：刷某某驱动，用某挂等等）
- [ ] **附加截图或视频证据**（清晰可见的涉及作弊的语言或行为）
- [ ] 标注作弊言论或行为发生的日期（如可能）
- [ ] 标注相关的社交平台

❌ **以下提交将被拒绝：**

- 没有证据支持的指控
- 仅基于个人猜测的投诉
- 不明确的用户身份信息
- 不实描述
